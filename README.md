## ✨ المزايا

### البنية السحابية والمنشآت
- 🔐 **مصادقة متعددة المنشآت** — جلسات آمنة (scrypt) مع انتقال سلس بين منشآت المستخدم الواحد
- 🏢 **تعدد المستأجرين الكامل** — عزل بيانات تام لكل منشأة (شركة / مؤسسة / متجر)
- 👥 **فريق وأدوار RBAC** — خمسة أدوار: مالك، مدير، محاسب، مبيعات، مشاهِد
- 💼 **باقات SaaS** — تجريبية، Basic، Pro، Enterprise مع لوحة تسعير ترحيبية
- 🛡️ **لوحة إدارة المنصة** — للمدير العام: المنشآت، المستخدمون، الاستخدام، تعليق الحسابات

### المبيعات والفواتير
- 🧾 **فواتير مبيعات** مع ضريبة قيمة مضافة، خصومات، تفقيط عربي، وطباعة احترافية
- 🌐 **تعدد العملات** — أصدر الفواتير (بيعاً وشراءً) بأي عملة (USD/EUR/AED…) مع سعر صرف، والقيود المحاسبية تُرحَّل تلقائياً **بمعادل الريال السعودي** مع عرض المكافئ في القوائم
- 📋 **عروض الأسعار** — أنشئ عرضاً ببنود وخصم وضريبة وسريان، ثم **حوّله لفاتورة بضغطة واحدة** (مع ترحيل المخزون والقيود تلقائياً)
- 🔁 **الفواتير المتكررة** — قوالب فوترة دورية (أسبوعي/شهري/ربعي/سنوي) ببنود وضريبة وطريقة دفع، تولّد فاتورة كاملة بضغطة زر (مخزون + قيود + QR) وتجدول التشغيل القادم تلقائياً
- ↩️ **المرتجعات** — إشعارات دائنة (مرتجع مبيعات) ومرتجع مشتريات مرتبطة بالمستند الأصلي، بعكس المخزون والقيود والضريبة آلياً
- 📱 **رمز QR لزتكا** — توليد حافظة TLV المشفّرة Base64 وعرضها على الفاتورة
- 🖨️ **طباعة PDF** بنسخ عربية منسقة للعميل والمالية
- 🛒 **نقطة بيع (POS)** — واجهة سريعة للكاشير مع سلة، بحث منتجات فوري، ودفع نقدي

### المشتريات والمصاريف والمخزون
- 📦 **مشتريات ومورّدون** مع قيود تلقائية للمخزون والدائنين
- 💸 **مصاريف** مصنّفة على حساباتها مع ترحيل محاسبي مباشر
- 🏷️ **مخزون** — منتجات بـ SKU وفئات وعلامات تجارية، وتكلفة وسعر بيع، وتحديث الكميات آلياً بالحركة
- 👥 **عملاء وموردون** ببطاقة كاملة تشمل العنوان الوطني السعودي (رقم مبنى، شارع، حي، مدينة، رمز بريدي، رقم إضافي)

### المحاسبة (قيد مزدوج)
- 📚 **دليل حسابات جاهز** — شجرة حسابات سعودية معيارية قابلة للتوسيع (25 حساباً تشمل الرواتب والتأمينات والإهلاك)
- ⚖️ **قيود تلقائية** — كل فاتورة/مشترى/مصروف يولّد قيده المزدوج المتوازن تلقائياً
- 💰 **المدفوعات والسندات** — سندات قبض (تحصيل من العملاء) وسندات صرف (دفع للموردين) مرتبطة بالفواتير أو حرّة، مع ترحيل محاسبي فوري وعكس الأثر عند الحذف
- 🔍 **مسح وترحيل** — إدارة القيود اليدوية والمراجعة
- 📊 **تقارير مالية** — ميزان المراجعة، قائمة الدخل، الميزانية العمومية، **تدفق النقد** (تشغيلي/استثماري/تمويلي)، أعمار الذمم المدينة والدائنة، حركة المخزون

### الموارد البشرية والرواتب
- 👥 **سجل الموظفين** — الهوية، المسمى، الأيبان والبنك، الراتب الأساسي والبدلات (سكن/أخرى) والاستقطاعات
- 🏦 **التأمينات GOSI** — احتساب آلي لحصة الموظف (9.75%) وحصة المنشأة (11.75%) على وعاء (الأساسي + السكن) مع إعفاء غير الخاضعين
- 🗓 **مسيرات شهرية** — شغّل مسير الشهر بضغطة: قسائم لكل موظف + **قيد آلي متوازن** (مدين مصروف الرواتب والتأمينات / دائن مستحقات GOSI والرواتب والسلف)
- 🧾 **قسائم الرواتب** — عرض تفصيلي لكل مسير مع الطباعة

### الأصول الثابتة والإهلاك
- 🏭 **سجل الأصول** — التكلفة، القيمة التخريدية، العمر الإنتاجي، وطريقة القسط الثابت، مع صافي القيمة الدفترية لحظياً
- 📅 **ترحيل إهلاك دوري** — قيد شهري آلي لكل فترة (مدين مصروف الإهلاك / دائن مجمع الإهلاك) مع منع الازدواج والتوقف عند الإهلاك الكامل
- 🚛 **التخريد** — إخراج الأصل بمبلغ بيع مع قيد ربح/خسارة التخريد الآلي

### الحوكمة وأمان البيانات
- 🕵️ **سجل التدقيق (Audit Log)** — كل عملية حساسة (بيع، سند، إعداد، عضو، باقة، رواتب، إهلاك، دخول) تُسجّل بالمستخدم والوقت والتفاصيل — متاح للمالك والمدير
- 💾 **نسخ احتياطي وتصدير** — تنزيل نسخة JSON كاملة من بيانات المنشأة (فواتير، قيود، جهات، مخزون، مدفوعات، عروض) بضغطة واحدة

### الضريبة والفاتورة الإلكترونية (زتكا)
- 🧮 **إقرار ضريبي VAT** — احتساب الإقرار الشهري/الربعي (مبيعات خاضعة، صفرية، معفاة، مشتريات) مع مراجعة القيود المرتبطة
- 🇸🇦 **زتكا — المرحلة الثانية**:
  - **QR TLV** — رمز الاستجابة السريع بصيغة Tags 1–9 المتوافقة
  - **XML UBL** — توليد فاتورة إلكترونية بصيغة UBL 2.1 (388 فاتورة / 381 إشعار دائن)
  - **محاكاة الإرسال** — بيئة محاكاة (Simulation) للتحقق قبل الربط الفعلي
  - **الإرسال الفعلي المعتمد (CSID)** — أدخل اعتماد CSID وسرّه والمفتاح الخاص EC P-384 وشهادة التوقيع من **بوابة فاتورة** (فطورا) بإعدادات المنشأة، فيوقّع النظام الفاتورة بـ**ختم تشفيري ECDSA** ويرسلها لنقاط النهاية الرسمية (`gw-fatura.zatca.gov.sa`) بوضعي المحاكاة أو الإنتاج، ويعرض نتائج التحقق الفعلية من البوابة

> ⚠️ **توضيح الاعتماد**: رمز CSID الحقيقي يُصدر حصراً عبر بوابة هيئة الزكاة والضريبة والجمارك (فطورا) بعد تسجيل وحدة الفاتورة (EGS) واجتياز فحص الامتثال — النظام جاهز للتفعيل فور إدخال البيانات، وقبل ذلك يعمل الإرسال بوضع المحاكاة الكامل.

### التواصل والذكاء
- 🔔 **إشعارات داخلية** — تنبيهات فورية للأحداث (فاتورة جديدة، دعم فني، انخفاض مخزون…)
- 🎫 **دعم فني** — نظام تذاكر مع **رد ذكي آلي** يقترح حلولاً من قاعدة معرفة
- 🤖 **مساعد محاسبي AI** — شات يسأل عن رصيد حساب، مبيعات شهر، إجراء قيد… (مزوّد Z.ai)
- 📧 **بريد إلكتروني** — عبر Resend أو وضع محاكاة يسجّل الرسائل داخلياً
- 💬 **واتساب** — إرسال حقيقي عبر Meta Cloud API أو توليد روابط wa.me جاهزة

## 🚀 التشغيل المحلي

### المتطلبات
- [Bun](https://bun.sh) v1+ (أو Node 20+ مع npm)

### الخطوات

```bash
# 1) تثبيت الاعتماديات (يولّد عميل Prisma تلقائياً عبر postinstall)
bun install

# 2) توليد ملف البيئة — اختياري:
#    المشروع يأتي مع .env جاهز (مسار نسبي يعمل من أي مكان)،
#    وإن وجد السكربت ملفاً موجوداً فسيخبرك ويتابع دون مشاكل
bun run env:generate

# 3) إنشاء جداول قاعدة البيانات (لا يلزم إذا نزّلت الحزمة مع db/custom.db)
bun run db:push

# 4) البيانات التجريبية (اختياري — لكنه يعطيك نظاماً حياً كاملاً
#     ويزرع الصفحات التسويقية العامة إن كانت فارغة)
bun run seed

# 5) التشغيل (يمكن تغيير المنفذ: PORT=3001 bun run dev)
bun run dev
```

ثم افتح `http://localhost:3000` — **الصفحة الرئيسية هي الموقع التسويقي**،
ومنه أزرار «تسجيل الدخول» و«جرب مجاناً» للانتقال إلى شاشة الدخول.

### 🔑 بيانات الدخول التجريبية (بعد seed)

| المستخدم | كلمة السر | الدور |
|---|---|---|
| `admin` | `admin123` | **مدير المنصة** — الوصول الكامل ولوحة الإدارة |
| `sara` | `sara123` | محاسب — شركة الأفق للتجارة |
| `khaled` | `khaled123` | مبيعات — شركة الأفق للتجارة |
| `mona` | `mona123` | مالك — متجر الواحة (لتجربة نقطة البيع) |

> البيانات التجريبية تشمل 3 منشآت بباقات مختلفة، مع منتجات وعملاء و24 فاتورة (منها فاتورتان بالدولار) ومسير رواتب كامل و3 أصول مُهلكة جزئياً وقالبي فوترة متكررة و76 قيداً محاسبياً — لتجربة كل شاشة فوراً.

## ⚙️ متغيرات البيئة

كل المتغيرات موثّقة بالعربية في [`.env.example`](.env.example)، وللمولّد التفاعلي:

```bash
bun run env:generate --help
```

| المتغير | إلزامي | الوصف | الافتراضي عند الغياب |
|---|---|---|---|
| `DATABASE_URL` | ✅ | رابط SQLite — يفضَّل مسار مطلق في الإنتاج، مثل `file:/home/user/erp/db/custom.db` | — |
| `APP_URL` | ✅ | رابط التطبيق العام — يُستخدم في روابط البريد والواتساب | `http://localhost:3000` |
| `PORT` | ✅ | منفذ الخادم | `3000` |
| `NODE_ENV` | ✅ | `production` / `development` | — |
| `RESEND_API_KEY` | ➖ | مفتاح [Resend](https://resend.com) — فعّله ليرسل البريد فعلياً | **وضع محاكاة**: تُسجَّل الرسائل داخلياً |
| `EMAIL_FROM` | ➖ | عنوان المرسل، مثل `ERP <noreply@domain.com>` | `ERP <onboarding@resend.dev>` |
| `WHATSAPP_TOKEN` | ➖ | توكن واتساب الدائم من Meta | **وضع محاكاة**: روابط wa.me |
| `WHATSAPP_PHONE_ID` | ➖ | معرّف رقم الهاتف في Cloud API | — |

> 💡 النظام مصمّم ليعمل بلا أي تكامل خارجي — أضف المفاتيح متى ما جهزت.
